Frequently Asked Questions (FAQ)

Find answers to some of the most commonly asked questions about the Student Profile & Course Portal.

What is the Student Profile & Course Portal?

This portal is a simple HTML website that showcases a student's profile, courses, grades, feedback form, and contact information.

What technologies are used in this project?

This project is developed using only HTML. No CSS or JavaScript has been used in this phase.

Can I submit feedback through this website?

The feedback form is available for demonstration purposes only and does not store or send data.

Can I view the student's grades?

Yes. The Grades page displays the student's marks in a structured table.

Can I contact the student?

Yes. The Contact Us page contains the student's email address, phone number, and office address.

Will more features be added later?

Yes. Future phases of the project will include CSS for styling and JavaScript for interactivity.
